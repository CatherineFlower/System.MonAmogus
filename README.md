# MonAmogus

MonAmogus — веб-приложение для мониторинга доступности интернет-сервисов и веб-ресурсов.  
Система позволяет выполнять HTTP-проверки сайтов, отслеживать состояние сервисов, фиксировать клиентские события и отображать результаты мониторинга через веб-интерфейс.

### [Репозиторий проекта](https://github.com/CatherineFlower/System.MonAmogus)


---

# Основные возможности

- Мониторинг доступности сайтов
- Проверка HTTP-ответов сервисов
- Анализ времени ответа
- Отображение текущего статуса сервисов
- История выполненных проверок
- Логирование клиентских JavaScript-событий
- Административная панель
- Авторизация администратора
- Добавление, редактирование и удаление сервисов
- REST API
- Docker-развертывание

# Запуск через Docker

## 1. Клонирование репозитория

```bash
git clone https://github.com/CatherineFlower/System.MonAmogus.git
cd System.MonAmogus
```

---

## 2. Сборка контейнера

```bash
docker compose build
```

---

## 3. Запуск проекта

```bash
docker compose up
```

Для фонового режима:

```bash
docker compose up -d
```

---

# Остановка контейнеров

```bash
docker compose down
```

# Административная панель

После авторизации администратор может:

* добавлять сервисы;
* изменять сервисы;
* удалять сервисы;
* запускать проверки вручную;
* просматривать историю проверок;
* анализировать состояние сервисов.

---

# Статусы сервисов

| Статус           | Описание                    |
| ---------------- | --------------------------- |
| Доступен         | Сервис работает корректно   |
| Проблемы         | Обнаружены частичные ошибки |
| Недоступен       | Сервис не отвечает          |
| Таймаут          | Превышено время ожидания    |
| Ошибка сети      | Ошибка подключения          |
| Ожидает проверки | Проверка ещё не запускалась |

# REST API

## Получение списка сервисов

```http
GET /api/services
```

## Выполнение проверки сервиса

```http
POST /api/services/{id}/check
```

## Получение истории проверок

```http
GET /api/services/{id}/checks
```

## Получение dashboard-информации

```http
GET /api/services/{id}/dashboard
```

# Назначение проекта

Проект разработан как учебная система мониторинга сервисов и демонстрирует:

* создание REST API на FastAPI;
* работу с Docker;
* реализацию backend/frontend архитектуры;
* работу с HTTP-проверками;
* интеграцию базы данных;
* организацию административной панели;
* обработку клиентских событий.
