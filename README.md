# MonAmogus

## Структура MVP

Проект подготовлен как каркас для поэтапной реализации функционала (в соответствии с разделом 11 ТЗ по структуре приложения):

- `app/` — основной пакет приложения.
  - `app/main.py` — точка входа FastAPI, базовый `/health` endpoint.
  - `app/config.py` — объект настроек приложения.
  - `app/database.py` — заготовка слоя работы с БД.
  - `app/models.py` — будущие модели предметной области.
  - `app/schemas.py` — будущие схемы валидации/сериализации.
  - `app/scheduler.py` — заготовка для фоновых задач.
  - `app/services/` — бизнес-логика и сервисные классы.
  - `app/routers/` — HTTP-роуты и маршрутизация API.
  - `app/templates/` — HTML-шаблоны (если потребуется серверный рендеринг).
  - `app/static/css/` — стили.
  - `app/static/js/` — клиентские скрипты.
- `demo/` — демо-данные, демо-сценарии и вспомогательные ресурсы для презентации.
- `tests/` — автотесты.
- `run.py` — локальный запуск MVP.
- `requirements.txt` — минимальные зависимости.

## Краткий сценарий запуска MVP

1. Создать и активировать виртуальное окружение.
2. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустить приложение:
   ```bash
   python run.py
   ```
4. Проверить доступность:
   - API: `http://127.0.0.1:8000`
   - Healthcheck: `http://127.0.0.1:8000/health`

## Проверка соответствия структуре из ТЗ

Созданы требуемые каталоги и минимальные файлы для старта MVP:

- Каталоги: `app/`, `app/services/`, `app/routers/`, `app/templates/`, `app/static/css/`, `app/static/js/`, `demo/`, `tests/`.
- Файлы: `app/main.py`, `app/config.py`, `app/database.py`, `app/models.py`, `app/schemas.py`, `app/scheduler.py`, `run.py`, `requirements.txt`.

Структура пригодна для поэтапного расширения: роутеры и сервисы можно добавлять независимо, модели и схемы развивать по мере появления доменных сущностей, а тесты — наращивать параллельно функционалу.
